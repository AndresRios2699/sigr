# Registro de Cambios (Changelog)

Todas las modificaciones notables en el proyecto "Sistema Integral de Gestión de Restaurante (SIGR)" serán documentadas en este archivo.

El formato se basa en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto se adhiere a [Semantic Versioning](https://semver.org/lang/es/).

## [1.0.0] - 2024-05-22
### Añadido (Added)
- Lanzamiento inicial de la Línea Base del proyecto.
- **Seguridad:** Implementación de Login con roles (Admin/Mesero).
- **Base de Datos:** Configuración inicial de SQLite con tablas (usuarios, platos, pedidos).
- **Interfaz:** Dashboard principal con visualización de menú.
- **Funcionalidad:** Sistema de registro de pedidos por mesa.
- **Documentación:** Archivo README con instrucciones de despliegue.

### Faltante / Por Hacer (To-Do)
- Módulo de facturación electrónica.
- Edición de platos desde el sistema (CRUD completo).
- Reportes exportables a Excel.
