# SIGR - Sistema Integral de Gestión de Restaurante

## Descripción
Sistema web para la gestión de pedidos, menú y usuarios de un restaurante.
Esta versión corresponde a la **Línea Base v1.0**.

## Instalación
1. Clonar repositorio.
2. Instalar dependencias: `pip install -r requirements.txt`
3. Ejecutar: `python src/app.py`
4. Acceder a `http://localhost:5000`
